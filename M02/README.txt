Encryption Demostration
by Jennifer Bowers 9/1/2026

A Demostration of Asymmetric and Symmetric Encryption methods for the M02 Encrypt/Decrypt Demo Assignment in Python

Features
Choosing between Asymmetric and Symmetric encryption methods, taking input of a message to encrypt, displaying keys used, and finally offering decryption of the message.

Prerequisites and installation
This application requires the installation of Python libraries "RSA" and "Cryptography" before running.

Application Logic
In the terminal, you will be first asked to enter 1 for Asymmetric encryption or 2 of Symmetric encrpytion. 
If not 1 or 2, then the message "Invalid input. Please enter 1 or 2" is displayed.
Then you need to enter a message to encrypt. 
In this demostration, I used "Hello, Professor Osaji! Today is a beautiful! I hope you are doing well."
It will then print out the encrypted message.
You are given the option to decrypt the current message, which will produce the keys used and the decoded message, or skip.
Finally, the option to run another encryption is given or it exits the program loop.
